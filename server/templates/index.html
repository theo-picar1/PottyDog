System Overview

Motion Detection

A PIR sensor detects heat-based motion near the door and categorizes activity in real time.

Edge Processing

A Raspberry Pi processes sensor input locally and transmits events securely.

Live Web Interface

The dashboard updates instantly to reflect current motion state and activity.

Cloud Messaging

PubNub enables low-latency communication between the device and the web client.

Implemented Features

Real-Time Motion Status

Displays basic motion, no motion, or sustained waiting behavior.

Potty Activity Logging

Log potty events with type selection and optional notes.

User Authentication

Secure login and registration with hashed password storage.

Daily Activity Summary

Dashboard shows daily counts and most recent activity.

Profile Management

Edit username and associated dog name.

Device Status Feedback

Auditory signal confirms device readiness.
